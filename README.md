# FTG Marketplace

Static landing page for the FTG Marketplace preview.

## Hosting

This version contains no internal content and can be hosted with GitHub Pages from the `main` branch using the repository root.

## Local files

- `index.html` - single-page static site
- `.nojekyll` - disables Jekyll processing for GitHub Pages
- `staticwebapp.config.json` - optional Azure Static Web Apps configuration
